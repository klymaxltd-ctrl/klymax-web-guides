# Préparer un inventaire de pages web

Une ressource de [Klymax](https://klymax.fr/) pour préparer un projet de création ou de refonte de site web.

Le notebook examine un tableau CSV contenant les URL, les titres, les descriptions et les H1. Il signale les champs manquants et les titres identiques sur plusieurs pages afin de préparer une revue humaine. Le résultat ne constitue pas un score SEO.

[Ouvrir le notebook dans Google Colab](https://colab.research.google.com/github/klymaxltd-ctrl/klymax-web-guides/blob/main/inventaire-pages-web.ipynb)

## Utilisation

1. Ouvrez le notebook et faites une copie dans votre espace.
2. Remplacez les données d’exemple par votre inventaire de pages.
3. Exécutez la cellule puis vérifiez les pages signalées dans votre navigateur.

Le code utilise uniquement la bibliothèque standard de Python et ne contacte aucun site. Le fichier de démonstration contient trois pages fictives et permet de vérifier le fonctionnement avant d’utiliser un export réel.
